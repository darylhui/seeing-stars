Welcome 👋

This is a clash-free timetable planner for NTU. Nothing is preloaded — you bring your own modules, and everything stays saved on this device only.

  1. Get your module files. On NTU’s official STARS Planner, open each module’s Content of Course page and save it (the .html file). One file per module.
  2. Import them. Tap Import, choose Core / MPE / Other, then select the files. Re-import anytime a module changes.
  3. Build your plan. In Catalog, tap + to add a module. Open it to pick an index — green dots fit your plan, red ones clash.
  4. Optimize. Tap Optimize, set your priorities (fewest days, early start, minimal gaps, etc.) and any constraints, then apply a suggested combination.
  5. Export. Export CSV saves your chosen index plus the next-best alternatives for every module.

Tip: lectures can be treated as optional via the Ignore lectures toggle, so lecture-only days count as free. Reopen this guide anytime with the ? button.

Export to Calendar (.ics)

Creates an .ics file you can import into Google Calendar, Apple Calendar, or Outlook. Each session becomes an individual event for the exact weeks it runs.

Events are exported with a COLOR property (RFC 7986) matching each module's colour. Google Calendar maps imported colours to its nearest preset — for exact colours you may need to set them manually, or import each module into a separate calendar.
